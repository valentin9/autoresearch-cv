# Task Scope

## Description

Train a model to detect and classify the font used in a text region of an image.
Given an input image containing rendered text, the model should identify which font
(by name) was used to render that text.

The input is a cropped image patch containing text rendered in a single font.
The model outputs a font class label corresponding to the font name.

Classes: one class per font name (e.g. `Arial`, `Times New Roman`, `Roboto`, `Georgia`, etc.).
The exact class list is defined in the metadata below.

**Research goal**: Find a novel approach that achieves strong font classification with limited
training data. Sample efficiency is a core research objective — the approach should not rely
on scale to succeed, and demonstrating good performance at 2k samples/class is part of what
makes it novel.

Known challenges:
- Fine-grained visual similarity between fonts (e.g. serif vs. serif variants)
- Variation in font size, color, background, and rendering quality
- Some fonts differ only subtly (e.g. `Helvetica` vs. `Arial`)

This task is well-suited for synthetic data: render text strings using known fonts onto
varied backgrounds, then label by font name. See `tools/` for synthetic generation utilities.

## Dataset

Dataset is already generated at `~/.cache/autoresearch/datasets/font_detection/`.
**Do NOT regenerate** unless explicitly asked — use `uv run prepare.py --validate-only` to check.

Key properties of the current dataset (generated by `tools/font_generator.py`):
- **Greyscale** (BW) images — color is irrelevant for glyph shape and only adds noise
- **Multi-line paragraphs** — 2–4 lines, ~12 chars/line wrap → ≥50 chars total per image
- **Tight letterbox crop** — text block fills ~55% of the 224×224 image; aspect ratio preserved (≤20% distortion)
- **Font size**: 36–72px rendered on a large canvas then letterboxed
- **Fonts**: Arial/Georgia/Times New Roman from exact system paths; all others from Google Fonts via GitHub
- **Scale**: 2000 train / 400 val per class, 15 classes = 30k train / 6k val total

Sanity check result (300 steps, pretrained ResNet-18): val_f1_macro ≈ 0.52, val_acc ≈ 0.87.

## Experiment History & What to Re-run

All experiments before commit `581b14e` are **invalid** — they used a broken dataset:
- Georgia mapped to SFGeorgian (Georgian alphabet script, not the typeface)
- Text occupied only 1–3% of image pixels (too small to learn from)
- Images were squished with up to 9:1 aspect ratio distortion
- Single-line only, sometimes as few as 3 characters

**Experiment plan** (restart from scratch on the fixed dataset):

1. **Pretrained ResNet-18 baseline** (`timm`, no grad accum, bs=64, lr=3e-4, 50-step warmup)
   - Purpose: establish a ceiling and confirm the pipeline works end-to-end
   - Expected: val_f1 > 0.60 after full 20-min run

2. **ConvNeXt-Micro from scratch** (the original baseline model in train.py)
   - Purpose: first from-scratch result on the clean dataset
   - Expected: lower than pretrained, but should converge meaningfully

3. **From there**: novel architecture search — see `program.md` for directions

**Known training bugs (fixed):**
- Time-based LR warmup → LR stays near-zero for the first ~2 min. Use step-count warmup.
- `gc.freeze()/gc.disable()` after step 0 — unnecessary, remove it.
- Grad accumulation with a short warmup causes the checkpoint evals to fire before the model has converged. Use no grad accum or delay first eval to step ≥ 300.

## Dataset Generation Notes (for reference / future tasks)

See `tools/font_generator.py` for the full implementation. Key decisions:

1. **Font sources**:
   - Arial, Georgia, Times New Roman: exact system paths (see `SYSTEM_FONT_EXACT` dict)
   - All others: GitHub raw URLs from `google/fonts` repo (see `FONT_DIRECT_URLS` dict)

2. **Rendering**:
   - Multi-line paragraph, ≥50 chars, ~12 chars/line wrap
   - Greyscale (R=G=B), no colour jitter
   - Font size 36–72px, letterbox resize to 224×224
   - Light blur + noise augmentation (10% chance each)

3. **What NOT to do** (learned the hard way):
   - Don't use fuzzy system font search — it picks up wrong fonts (SFGeorgian, Roboto Mono)
   - Don't resize with squish — always letterbox
   - Don't truncate text below ~15 chars — use word wrap instead
   - Don't render single-line text at large font on a wide canvas — produces 9:1 crops

Target: 2000+ train / 400+ val per class, balanced.
